### 03. Two-Bot Launch Relay — Multi-Agent AI

A multi-agent workflow built using CrewAI and a locally running Ollama model.

The system features two specialist agents:

- **Source Editor:** Reviews source information, prepares a source brief, and obtains human approval before initiating the handoff.
- **Launch Producer:** Uses the approved brief to generate an announcement draft and a structured run-of-show CSV.

A final QA stage reviews the generated deliverables and records the validation results.

- **Tools:** Python, CrewAI, Ollama, Qwen 3.5 2B
- **Project folder:** [`two_bot_launch_relay`](./two_bot_launch_relay/)
- **Detailed documentation:** [`Project README`](./two_bot_launch_relay/README.md)

*The workflow prepares drafts for human review; it does not publish or distribute content automatically.*
